Установка в Mozilla Firefox (Windows)

Терминал не нужен. Нужен Firefox 121 или новее.

У вас должна быть папка bpm-monitor-simple-V2_mozilla с файлом manifest.json внутри.

Шаги

  1. Откройте Firefox.
  2. В адресной строке введите:
    about:debugging#/runtime/this-firefox и нажмите Enter.
  3. Нажмите «Загрузить временное дополнение…».
  4. Откройте папку расширения и выберите файл manifest.json → «Открыть».
  5. Разрешите уведомления, если Windows спросит.
  6. Откройте дашборд BPM «Работа», нажмите иконку расширения → «Проверить сейчас».
Важно: после полного закрытия Firefox расширение нужно загрузить снова (Шаги 2–4). Так Firefox защищает от неподписанных дополнений. Для постоянной установки нужна подпись через Mozilla / IT.
