# Установка «Монитор BPM V2» в Mozilla Firefox (Windows)

Для обычных пользователей. **Терминал не нужен.**

Нужен Firefox версии **121 или новее** (обычный Firefox с сайта mozilla.org).

---

## Что вы должны получить

Папку с названием примерно:

`bpm-monitor-simple-V2_mozilla`

Внутри должны быть файлы, среди них обязательно:

- `manifest.json`
- `background.js`
- `popup.html`
- `icon.png`

Эту папку можно положить, например, в Документы или на Рабочий стол. **Не удаляйте и не переименовывайте файлы внутри.**

---

## Установка за 5 шагов (Windows)

### Шаг 1. Откройте Firefox

Запустите Mozilla Firefox как обычно.

### Шаг 2. Откройте страницу отладки дополнений

1. Кликните **один раз** по адресной строке (сверху, где пишется адрес сайта).
2. Сотрите всё, что там есть.
3. Введите точно так (можно скопировать и вставить):

```text
about:debugging#/runtime/this-firefox
```

4. Нажмите **Enter**.

Откроется служебная страница Firefox «Отладка».

### Шаг 3. Загрузите расширение

1. Найдите кнопку **«Загрузить временное дополнение…»**  
   (в английской версии: **«Load Temporary Add-on…»**).
2. Нажмите на неё.
3. В окне выбора файла откройте папку `bpm-monitor-simple-V2_mozilla`.
4. Выберите файл **`manifest.json`** (не папку, а именно этот файл).
5. Нажмите **«Открыть»**.

Если всё прошло успешно, в списке появится  
**«Монитор задач BPM V2 (Firefox)»**.

### Шаг 4. Разрешите уведомления

Если Windows или Firefox спросят про уведомления — нажмите **Разрешить**.

### Шаг 5. Проверьте работу

1. Откройте рабочий сайт BPM (дашборд «Работа») и войдите в систему.
2. На панели Firefox нажмите иконку расширения (пазл / значок монитора).
3. Нажмите **«Проверить сейчас»**.

Должен появиться список задач ПРЗ / ФРЗ / ПКМ.

---

## Важно знать

### После закрытия Firefox расширение пропадёт

Это **временная** установка (так устроен Firefox для неподписанных дополнений).

После полного закрытия Firefox нужно снова выполнить **Шаги 2–3** (это быстро: около минуты).

Вкладку BPM при работе лучше **не закрывать** (можно свернуть).

### Если кнопка «Загрузить временное дополнение» не видна

- Убедитесь, что открыт именно адрес `about:debugging#/runtime/this-firefox`
- Обновите Firefox до последней версии
- На рабочем компьютере спросить у IT, не блокирует ли политика установку дополнений

### Если пишет ошибку про подпись / signature

Обычный Firefox не ставит «навсегда» неподписанные расширения.  
Временная загрузка через `about:debugging` — правильный и безопасный способ для внутренней программы.

Постоянная установка для всех сотрудников возможна только после **офиставки подписанного файла** через Mozilla (делает разработчик/IT), либо через корпоративную политику Firefox.

---

## Куда писать, если не получилось

Проверьте по порядку:

1. Выбран именно файл `manifest.json` из папки `bpm-monitor-simple-V2_mozilla`
2. Firefox не старше требований (121+)
3. Сайт BPM открыт и вы в нём авторизованы
4. Уведомления Windows для Firefox не запрещены

Подробная инструкция по работе с задачами, цветами и схемами — кнопка **«Инструкция»** внутри расширения.
