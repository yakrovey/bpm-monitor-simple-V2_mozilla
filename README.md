# Монитор задач BPM V2 — Firefox

Отдельная сборка расширения **только для Mozilla Firefox**.

## Для пользователей (Windows)

Откройте файл **[INSTALL.md](INSTALL.md)** или **[INSTALL.html](INSTALL.html)** — установка без терминала, пошагово.

Кратко: в Firefox открыть `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → выбрать `manifest.json`.

## Для разработчика

- Манифест уже Firefox MV3 (`background.scripts` + `browser_specific_settings.gecko`)
- ID: `bpm-monitor-v2-mozilla@yakrovey`
- Chromium-версия лежит рядом: `bpm-monitor-simple-V2`
